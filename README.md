#RECIPE RECOMMENDATION SYSTEM USING PYTHON AND TKINTER#
####The Kitchen Mate Recipe Recommendation System shows how Python and Tkinter can be combined with CSV file handling to solve an everyday household problem. By storing 50 classic Indian vegetarian recipes and using a flexible substring-matching algorithm, the app helps users quickly discover what dishes they can cook with the ingredients already in their kitchen. The project makes practical use of core Python concepts including object-oriented programming, lists, dictionaries, string methods, loops, and file I/O. In the future, this application can be expanded by adding recipe photos, cooking timers, dietary filters (such as vegan or high-protein), and an option to edit or delete saved recipes.####
